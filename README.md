## 同价的两种买法：5Mbps 不限量和 10Mbps/1TB

两个 $24.99/年的 Premium 套餐硬件一模一样，区别只在带宽和流量怎么分配。

**5Mbps 不限流量**的天花板可以算出来：5Mbps × 86400 秒 × 30 天 ÷ 8 ≈ **1.62TB/月**，这是理论上限，实际有协议开销，打九折左右。好处是不用盯流量，坏处是峰值只有 5Mbps，拉个 2GB 的文件要五六分钟。

**10Mbps/1TB** 峰值快一倍，但 1TB 按满速算只够跑 **9 天半**。剩下的时间要么限速用，要么闲置。

决策规则不复杂：

- 建站、跑 API、偶尔传大文件，选 10Mbps/1TB，1TB 对个人站和小团队够用，峰值也更舒服。
- 挂备份、做同步、长期在线跑任务，选 5Mbps 不限量。24 小时持续跑下来，它的月流量上限比 1TB 还高。
- 两个条件都要，就是 $9/月 的 10Mbps 不限流量，一年 $108，比年付特价贵约 **$83**。

这 $83 值不值，看你每天的实际用量。一天传不到 30GB，年付那台够用；每天都在搬几十 GB，月付方案省下的折腾比省下的钱重要。不限量套餐的公平使用条款资料里没查到，长期跑满会不会被限速，下单前值得开工单问一句。

## 线路：Premium 三网直连，Global 绕德国

同一个机房、同一个年付价，两条线的实际体验差一个数量级，这是买台湾机房最容易踩的坑。

### Premium 优化线路

测评机（就是 $24.99 那台 1 核 1G）的三网路由：

- **电信**：去程走 CN2 经香港到台湾；回程从台湾经香港走 CTGNet/CN2 直连回广州。
- **联通**：去程走 AS10099（CUG）经香港到台湾；回程经香港转到广州，接联通 4837 回内地。
- **移动**：去程走 CMIN2 到台湾；回程走 CMI 经香港直连回国。

三网都是双程各自骨干直连，中间绕一下香港，属于标准的“回国优化”做法。另一台 4 核 4GB / 20Mbps 的优化线路机在测评里录得大陆平均约 **88ms**，那台配置和这台不同，只能作为量级参考。

带宽实测（大陆三网 IPv4 多线程）：**下载最大 9.71Mbps，上传最大 12.22Mbps**，10M 口基本跑满，没有虚标。

### Global 国际线路

同价位的 Global 版本走的是完全不同的路径：

- 电信去程直连欧洲，接 retn 经德国回台湾。
- 联通去程直连德国，接 opentransit 转 retn 回台湾。
- 回程实测：广州电信 323.96 / 330.35ms，上海电信 305.84 / 338.86ms，广州联通 334.93–388.63ms，上海联通 349–355ms，北京联通 309–351ms，上海移动 242–353ms。路径普遍经日本、美国或香港绕行。

有测评对这条件给出过结论：国际线路的台湾 VPS 和优化线路差别很明显，大陆方向延迟和丢包都比较严重，适合纯亚洲或海外业务。这个判断和上面的数据对得上。
